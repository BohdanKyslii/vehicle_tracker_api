## 2026-08-04 — Фаза 6-7 `cars` задеплоєна, Фаза 8 дописана в гайд, Telegram-бот водіїв

### Що зроблено
- Backend `cars` (Фаза 6-7) — знайдено й виправлено 6 багів від
  ручного набору коду з `DJANGO_CODING_GUIDE.md`, задеплоєно.
- `DJANGO_CODING_GUIDE.md` — дописана Фаза 8 (`products`/`customers`/
  `waybills` views+urls), перевірена наскрізь перед записом, код у
  репозиторії поки не набраний руками.
- Нова позапланова фіча — Telegram-реєстрація водіїв (бот, aiogram) і
  вхід через Telegram Mini App (`initData`, HMAC-перевірка),
  підтвердження заявки з вибором ролі прямо в Telegram. Детально —
  новий файл `TELEGRAM_BOT_SETUP.md` у корені `vehicle_tracker_api`.
- Прибрано дублікат `Driver.telegram_id` (`apps/cars`) — єдине джерело
  правди тепер `Profile.telegram_id` (`apps/accounts`, `unique=True`).

### Чому
Водії не мають корпоративної пошти, тому не можуть пройти звичайну
web-реєстрацію (username/email/пароль) — потрібен окремий шлях через
Telegram, де реєстрація зводиться до "поділитись контактом" однією
кнопкою.

### Статус
Backend задеплоєно на Pi. Frontend (Mini App сторінка + Telegram-кнопка
на сайті) закомічено локально, але push заблокований конфліктом з
`origin/main` — ще не розв'язано. Реальний бот через @BotFather ще не
створено — `TELEGRAM_BOT_TOKEN` порожній.

- Замінено Django стек на React 18 + TS + Tailwind.

- Оновлено структуру проєкту під React.

#### AI_AGENT_CONTEXT.md
