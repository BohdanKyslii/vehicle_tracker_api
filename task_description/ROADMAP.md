# ROADMAP — Загальна черговість фаз (Backend + Frontend)

Єдина "мапа": яка фаза в якому проєкті зроблена і що далі.
Детальні покрокові інструкції з кодом лишаються у своїх файлах:

- Backend: `DJANGO_CODING_GUIDE.md` (корінь `vehicle_tracker_api`)
- Frontend: `CODING_GUIDE.md` (корінь `vehicle_cost_tracker`)

Поточний стан і інциденти — `STATE.md`. Цей файл оновлюється, коли
фаза завершується або змінюється порядок.

> **Обидва гайди — сценарії для ручного набору, не changelog.** Статуси
> нижче звірені з реальним кодом обох репозиторіїв 2026-11-27.

## Обов'язкове правило: гілка на кожну фазу

В обох репозиторіях нова фаза = нова гілка від `main`:

```bash
git checkout main && git pull origin main
git checkout -b feature/faza-N-коротка-назва
# ... код, поетапні коміти ...
git push -u origin feature/faza-N-коротка-назва
# Pull Request → перевірити diff → Merge
```

- `main` — завжди робочий стан; push у `main` запускає автодеплой
  (після переносу — лише коли `DEPLOY_ENABLED=true`).
- Перед злиттям: backend `python manage.py check`, frontend `npm run build`.
